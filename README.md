# AI RAG Agent Project

Un projet simple pour comprendre et expérimenter les bases des architectures **RAG (Retrieval-Augmented Generation)** et des **Agents IA**.

## 🎯 Objectif
Permettre à une intelligence artificielle de répondre à des questions en se basant sur des documents privés, grâce à une recherche intelligente dans les données.

## 🛠️ Les fondamentaux du projet
1. **Ingestion :** Lecture et découpage des documents sources.
2. **Vectorisation :** Transformation du texte en représentations numériques pour trouver le sens.
3. **Recherche sémantique :** Récupération des passages les plus pertinents pour aider le modèle.
4. **Génération :** Production d'une réponse claire, précise et ancrée dans les documents.
